The 23 skills

Every skill in the pack, with its description and the tool categories it grants. Each is a plain SKILL.md in the standard Agent Skills format.

Two skills were removed in v0.2.0. review-security and simplify-code were dropped after multi-model A/B testing showed they provided no marginal value or actively hurt results. The pack keeps only skills that earn their place, per the candor-about-limits principle. The reasoning is documented in skills/REJECTED.md.
