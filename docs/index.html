The core foundation every knowledge worker needs

A portable kit of 23 general-purpose skills for creation, review, writing, research, and office formats. They give any AI agent the working skills a knowledge worker relies on, in a format any harness can load.

Why this pack exists

The pack exists to provide the core foundation every knowledge worker needs, and to augment smaller, more affordable models where testing shows skills matter most.

We test that claim rather than assert it. The pack ships a reproducible A/B testing program that measures each skill's marginal value: baseline (no skill) versus treatment (skill loaded), scored on a fixed rubric. The results are honest about where skills help and where they do not.

Strong models are already near the ceiling

Capable models score close to the maximum without any skill, so adding one changes little. Skills are not a substitute for a strong model.

Weaker models gain the most

On smaller, cheaper models the gains are largest. Code review quality nearly doubled on gemini-2.5-flash-lite, from a baseline of 3.67 to 7.0 out of 10 with the skill loaded.

Skills are tiered by what they add

An earlier single-model run sorted skills by the size of the gap they close: capability-creation skills (the baseline could not do the job at all, 10 to 20 times the gap), discipline skills (the baseline acted but acted wrongly, 2.5 to 5 times), and craft-reinforcement skills (1 to 2 times, consistency rather than ability).

We also report the failures. Two skills were removed after testing showed they added no value or actively hurt results. The testing page documents all of it, including the numbers.

This is an Open Pack Format pack

OPF is an open, harness-agnostic pack format: a manifest.json plus embedded files, installed, updated, and removed with zero native harness code. The spec lives in the opf-core repository.

Install

Install this pack with the pack-install skill, or by pointing any Agent Skills installer at skills/<name>/SKILL.md. There is no install.sh, because none is needed: each skill is a plain SKILL.md, so the generic Agent Skills install step is all any harness requires.

Validate

Validate the pack with scripts/validate-pack.sh. A local pre-commit hook and CI scanning run the same checks on every change.

See the repository README for the full install and validation details.
